## Mobile product implemented

- Full-screen source selector with `MI UBICACIÓN` and `UBICACIÓN COMPARTIDA`.
- Honest Google wording: no OAuth or official Location Sharing API is claimed.
- Explicit own-device permission screen; no automatic browser permission prompt.
- Shared-session onboarding and parser feedback without cookie values.
- Source-isolated mobile map shell with safe areas and three primary controls.
- Bottom sheet with source-specific actions.
- Change-source flow stops active watchers and cancels shared polling.
- Last source preference may be retained; coordinates and Google cookies are not stored in browser storage.
- Legacy Next.js API routes were removed from the mobile product tree because Python/gateway is the canonical backend.
